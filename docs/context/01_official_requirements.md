# 공식 요구사항 정리
출처: 강사 제공 내용(사용자 메시지에서 전달된 공식 요구사항)

## 1. 목적

- 단 하루 동안 AI를 도구 삼아 팀별 프로젝트에 몰입한다.
- 결과물뿐 아니라 **과정**도 중요하다.
- AI가 작성한 코드를 완벽히 내 것으로 소화해 그 원리를 설명할 수 있어야 한다.
- 낯선 기능도 Top-Down으로 빠르게 풀어내며 학습 민첩성을 높인다.
- 현업 레벨 기술을 직접 부딪쳐 보며 실무 감각을 깨운다.

## 2. 핵심 구현 요구사항

React의 핵심 개념인 **Virtual DOM** 과 **Diff 알고리즘** 을 구현한다.

### 필수 구현
- 브라우저의 DOM 정보를 읽어서 Virtual DOM 으로 변환하는 함수 작성
- 두 Virtual DOM 을 비교하여 변경된 부분을 찾아내는 Diff 알고리즘 작성

## 3. 검증용 웹 페이지 요구사항

페이지에는 다음이 있어야 한다.

- 실제 영역
- 테스트 영역
- Patch 버튼
- 뒤로가기 버튼
- 앞으로가기 버튼

### 동작 흐름
1. 웹 페이지 로드
   - 실제 영역의 샘플 HTML 코드를 Virtual DOM 트리로 변환
2. 방금 만든 Virtual DOM 으로 테스트 영역 렌더링
3. 사용자가 테스트 영역의 샘플 HTML 코드를 자유롭게 수정
4. Patch 버튼 클릭
   - 현재 테스트 영역 상태를 다시 Virtual DOM 으로 생성
   - 이전 Virtual DOM 과 diff 수행
   - 변경된 부분만 실제 영역에 렌더링
   - 새 Virtual DOM 을 state history 에 저장
5. 뒤로가기 / 앞으로가기 클릭
   - history 에 저장된 특정 Virtual DOM 으로 이동
   - 실제 영역과 테스트 영역이 함께 바뀌어야 함

## 5. 구현보다 더 중요한 이해 포인트

### 브라우저 / DOM
- Document / Window
- 브라우저에서 DOM 을 다루는 방법
- 실제 DOM 변화를 감지하기 위한 브라우저 API

### 성능 관점
- 실제 DOM 이 느린 이유
- Reflow / Repaint 관점

### Virtual DOM
- 구조
- 필요한 이유

### Diff 알고리즘
- 동작 방식
- 최소 변경을 찾기 위한 5가지 핵심 케이스
- 실제 DOM 반영 방법

### React 연결
- React 에서 실제 DOM 을 변경할 때 Virtual DOM 과 Diff 알고리즘이 어떻게 동작하는가
