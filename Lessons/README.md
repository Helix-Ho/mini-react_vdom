# Lessons 폴더 운영 규칙

이 폴더는 프로젝트가 끝난 뒤 복습용으로 남길 **학습 자산 폴더**다.

## 목적
- 각 마일스톤에서
  - 왜 구현했는지
  - 어떻게 구현했는지
  - 무엇을 검증했는지
  - 무엇이 남았는지
  를 남긴다.

## 반드시 들어가야 할 내용
- 왜 이 단계인가
- 이번 주 키워드와의 연결
- 핵심 함수/자료구조
- 검증 방법
- 직접 설명해볼 질문

## 작성 방식
- 새 마일스톤이면 새 파일
- 같은 마일스톤 보완이면 기존 파일 업데이트
- 장황한 회고보다 **다음에 다시 봐도 바로 이해되는 기록**을 남긴다.
